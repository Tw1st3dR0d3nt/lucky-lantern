Privacy Policy

Last updated: August 24, 2026

This Privacy Policy explains what information Lucky Lantern ("Lucky Lantern", "the Bot", "we", "us", or "our") processes when you use the Bot through Discord.

1. Information We Process

Depending on how you use Lucky Lantern, the current implementation may process:

  • Discord user IDs for command access and blacklist functionality.
  • Discord server IDs for server-specific data and server restrictions.
  • Discord display information available through Discord, such as a display name and avatar URL used in command embeds.
  • Killboard entries submitted through the Bot's killboard commands.
  • Blacklist records containing user IDs and server IDs restricted from using Lucky Lantern.

2. Information We Do Not Intentionally Collect

Lucky Lantern does not require message-content access to provide its commands. The Bot is configured with Discord's Guilds intent rather than a broad message-content intent.

Based on the current implementation, Lucky Lantern does not intentionally collect passwords, payment-card information, email addresses, or private Discord messages.

3. How Information Is Used

  • Respond to Discord slash commands.
  • Display applicable Discord display information in embeds.
  • Maintain server-specific killboard data.
  • Maintain user and server blacklist records.
  • Prevent restricted users or servers from using the Bot.
  • Operate, maintain, troubleshoot, and protect the Bot.

4. Stored Data

The current implementation stores persistent application data in local JSON files. Killboard information is stored separately by Discord server, while blacklist information contains relevant Discord user and server IDs.

Data is not used for advertising or sold to third parties by Lucky Lantern.

5. Discord

Lucky Lantern receives information through Discord when users interact with the Bot. Discord may independently process information under its own privacy policy and terms. Lucky Lantern does not control Discord's independent data processing.

6. Data Retention and Deletion

Persistent killboard and blacklist records may remain stored while needed for their corresponding features. Killboard entries can be removed through administrative commands, and blacklist records can be removed through the appropriate administrative commands.

If you believe information associated with your Discord account should be removed, contact the Lucky Lantern operator through the project's GitHub repository. A request may require enough information to identify the relevant Discord record.

7. Data Security

Reasonable measures are used to protect stored application data. However, no electronic storage or transmission system can be guaranteed completely secure.

8. Children's Privacy

Lucky Lantern is a Discord bot and is subject to Discord's age requirements and policies. We do not intentionally collect personal information from children independently of Discord.

9. Changes to This Privacy Policy

This Privacy Policy may be updated when Lucky Lantern's functionality, data practices, or legal requirements change. The latest version will be published here with an updated "Last updated" date.

10. Contact

For privacy questions or requests concerning Lucky Lantern, please contact the project operator through the project's GitHub repository.
