# 🏮 Lucky Lantern

A feature-rich Discord bot for fun interactive commands, games, and useful server utilities.

## ✨ Features

- 🎱 Eight Ball
- 🪙 Coin Flip
- 🎲 Dice Roller
- 🎰 Roulette
- 🔮 Random Choice
- 💀 Server Killboard
- 🛠️ Killboard management tools
- 🚫 Owner-managed user and server blacklist
- 💾 Persistent data storage
- ⚡ Lightweight Discord.js implementation

## 📋 Commands

### Fun

| Command | Description |
|---|---|
| `/fun eightball` | Ask the Magic 8-Ball a question |
| `/fun coinflip` | Flip a coin |
| `/fun dice` | Roll one or more dice |
| `/fun roulette` | Spin the roulette wheel |
| `/fun choose` | Randomly choose between multiple options |

### Killboard

| Command | Description |
|---|---|
| `/killboard` | View the server killboard |
| `/killboard <victim>` | Record a kill |
| `/edit-victim` | Manually edit a victim's tally |
| `/remove-victim` | Remove a victim |
| `/clearkillboard` | Clear the server killboard |

### Administration

Owner-only blacklist commands are available in the Lucky Lantern administration server.

| Command | Description |
|---|---|
| `/blacklist-user` | Blacklist a user |
| `/unblacklist-user` | Remove a user from the blacklist |
| `/blacklist-server` | Blacklist a server |
| `/unblacklist-server` | Remove a server from the blacklist |
| `/blacklist-list` | View the current blacklist |
